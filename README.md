# Data Folder

The raw dataset is not included in this repository to avoid uploading confidential or restricted data.

To run the notebook, place the dataset file named `booking.csv` in one of these locations:

1. `notebooks/booking.csv`
2. The repository root as `booking.csv`
3. Your local Downloads folder as `booking.csv`

The notebook expects the file name `booking.csv`.

After cleaning invalid reservation dates, the notebook uses 36,248 bookings for modeling.
